# 💸 FinSmart - Smart Money Management


FinSmart is a modern, AI-powered personal finance and budgeting application designed for college students and young professionals. FinSmart makes tracking your money, saving for the future, and analyzing your spending a premium, enjoyable experience.

## ✨ Features

* **🤖 AI Spending Analyzer:** Get personalized insights, daily tips, and spending warnings powered by AI.
* **👛 Digital Wallet:** Seamlessly track your balance, handle money transfers, and manage your recent payees.
* **🎯 Smart Budgeting:** Set budget limits across multiple categories (Food, Transport, Shopping, etc.) with real-time visual progress bars.
* **🔔 Budget Alerts:** Never overspend again with built-in alerts and smart tracking.
* **🪙 FinCoins Rewards:** A gamified savings experience where you earn FinCoins for saving money and hitting your budget goals. 
* **📊 Expense Reports:** Clean, interactive dashboards and visual representations of your income and expenses.
* **🌗 Dynamic Theming:** Full support for both Light and Dark modes built seamlessly into the UI.

## 🛠️ Technology Stack

* **Frontend:** React, Vite
* **Design:** Custom Vanilla CSS with advanced Glassmorphism utilities
* **Database & Auth:** Firebase / Firestore
* **AI Integration:** NVIDIA API (for AI Spending Insights)
* **Icons & Avatars:** SimpleIcons, UI-Avatars

## 🚀 Getting Started

### Prerequisites

You will need [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Rajesh-dev-stack/FinSmart.git
   cd FinSmart
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Set up Environment Variables**
   Create a `.env` file in the root directory and add your Firebase config and Groq API key:
   ```env
   VITE_FIREBASE_API_KEY="your_api_key"
   VITE_FIREBASE_AUTH_DOMAIN="your_auth_domain"
   VITE_FIREBASE_PROJECT_ID="your_project_id"
   VITE_FIREBASE_STORAGE_BUCKET="your_storage_bucket"
   VITE_FIREBASE_MESSAGING_SENDER_ID="your_sender_id"
   VITE_FIREBASE_APP_ID="your_app_id"
   VITE_NVIDIA_API_KEY="your_NVIDIA_api_key"
   ```

4. **Start the development server**
   ```bash
   npm run dev
   ```
